# 全国都市対抗選手権大会

## ファイル構成
- `index.html` : 画面
- `style.css` : デザイン
- `script.js` : 抽選・総当たり・順位・昇格降格
- `data/cities.json` : 128都市×19項目の原数値データ入力テンプレート

## GitHub Pages
1. リポジトリの同名ファイルをこの一式で置き換えます。
2. `data/cities.json` を含め、フォルダ構成をそのまま維持します。
3. Settings → Pages → Deploy from a branch → main / root を選択します。

## データについて
全128都市×19項目に数値を入力済みです。空欄・null・未確認はありません。ただし現在の数値は独自の簡易推計によるデモ値で、公式統計・実測値ではありません。各セルの `data_quality` は `推計値`、`sources` は推計であることを示しています。
公式値を確認できたら `values` に原数値、`years` に調査年、`sources` に公式出典を入力し、`data_quality` を `公式値` に変更してください。
単位や定義・対象年が異なる値を混同しないでください。実際の数値が入力されるまでは公平な試合判定を停止します。

## 対戦ルール
- 128都市を完全抽選で16リーグ×8都市に編成
- 各リーグ総当たり（各都市7試合、1リーグ28試合）
- 各評価項目を原数値のまま比較し、項目ごとの勝ち数で対戦勝者を決定
- 同点時は方向を考慮した19項目の合計値、さらに都市ID順で決定
- 上位3都市が1つ上のリーグへ昇格、下位3都市が1つ下のリーグへ降格
- 1部の上位昇格、16部の下位降格はなし

## 評価方向
`criteria[].better` が `higher` の項目は大きい方、`lower` は小さい方を評価します。大会主催者は定義を確認して必要なら変更してください。特に昼夜間人口比率、外国人住民割合、域外通勤通学割合などは大会の価値判断を含むため、方向は確定ルールとして扱う前に確認してください。
